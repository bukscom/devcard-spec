// HOW IT WORKS

Dead simple.
By design.

01 —

Create your devcard.md

Write your identity, vibe, stack, and AI preferences once. Takes 5 minutes.

02 —

Push to GitHub

Drop it in a public Gist or a dedicated repo. One raw URL is all you need.

03 —

Any tool reads it

AI tools fetch it at session start. No SDK. No API. Just markdown over HTTP.

04 —

You're known everywhere

Every tool knows your name, style, preferences. You never onboard yourself again.

// THE SCHEMA

Six sections.
Infinite identity.

🪪

## Identity

Your name, what to call you, your role, GitHub handle. The basics — but powerful.

⚡

## My Stack

Languages, frameworks, databases, tools. What you actually build with.

🎯

## My Vibe

Working style, strengths, weaknesses, likes, don'ts. Your personality in code form.

✍️

## Code Style

Indentation, naming, commits, PRs. How you write code — consistently.

🤖

## AI Preferences

Tone, length, behavior when stuck. How every AI tool should talk to you.

🚀

## Currently Working On

Your current focus. Gives every tool instant project context without extra words.
